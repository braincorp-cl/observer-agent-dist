Agente multiplataforma de **Observer RMM** (Windows, Linux, macOS). Binarios adjuntos abajo y publicados también en el CDN `agents.observer.cl`.

Esta versión completa el **monitoreo de actividad** (feature 049-C) con capturas de pantalla periódicas, sitios web y uso de red por aplicación. Todo sigue **apagado** salvo donde la consola lo encienda, y capturas y red se habilitan aparte del monitoreo.

## Cambios en esta versión

- **Capturas de pantalla periódicas.** Cada N minutos y solo con el usuario activo y la sesión desbloqueada. Se reducen (1366 px, JPEG o PNG según cuál pese menos), se suben a la consola y se borran del equipo. Las imágenes en negro se descartan. Si la consola ya no las quiere, el agente las apaga solo.
- **Sitios web por título.** El sitio se deduce del título de la ventana del navegador (sin leer historial ni interceptar tráfico); requiere que la consola registre títulos.
- **Uso de red por aplicación.** Conexiones TCP establecidas por proceso: minutos con red, pico de conexiones simultáneas y destinos distintos. No mide bytes ni contenido.
- **Falla hacia apagado.** Contra una consola anterior, capturas y red quedan apagadas.

## Lo que se verificó antes de publicar

| qué | resultado |
|---|---|
| Compilación / `go vet` / pruebas | verdes en los 3 SO |
| Sitios, red y reducción de capturas | pruebas unitarias (heurística de títulos, agrupación de conexiones, JPEG vs PNG, persistencia y servidor viejo) |

## Plataformas

- **Windows** — 64 bits y 32 bits (instaladores)
- **Linux** — `amd64`, `386`, `arm64`, `arm`
- **macOS** — `arm64` (Apple Silicon) y `amd64` (Intel)

## Instalación

La actualización es **automática** desde la consola. Capturas y red permanecen **apagadas** hasta que la consola las habilite.
